# aws-ai-ng

AWS Certified AI Practitioner (AIF-C01) Exam Trainer — Angular 22 Standalone PWA.

## Prerequisiti

- Node.js 22+
- npm

## Installazione

```bash
npm install
```

## Sviluppo

```bash
npm start
```

L'app sarà disponibile su `http://localhost:4200`.

## Build

```bash
npm run build
```

L'output viene generato nella cartella `dist/`.

## Test

```bash
npm test
```

## Sincronizzazione domande

```bash
npm run sync:questions
```
